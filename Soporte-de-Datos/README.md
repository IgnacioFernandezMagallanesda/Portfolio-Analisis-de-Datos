# Soporte de Datos

Proyectos de soporte sobre plataformas y procesos de datos: validación de cargas, calidad de datos, resolución de incidentes y documentación de tickets.

| Proyecto | Herramientas | Descripción |
|---|---|---|
| [Validación de calidad de datos post-carga](Validacion-Calidad-Datos-SQL) | MySQL, MySQL Workbench | 5 tickets de soporte sobre una tabla de staging: duplicados, nulos, valores fuera de rango, estados inconsistentes y cruce con tablas maestras. Cada uno con su diagnóstico, impacto, causa probable y registro del incidente. |
| [Monitoreo de procesos ETL y tickets](Monitoreo-Procesos-ETL-SQL) | MySQL, MySQL Workbench | 5 pedidos de soporte sobre cargas nocturnas: procesos con más fallas, filas perdidas en cargas OK, corridas que no se ejecutaron, duraciones anómalas y cumplimiento del SLA de tickets. |
